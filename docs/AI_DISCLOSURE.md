# AI disclosure

Neighborhood Hacks allows AI assistants and requires disclosure. This file is kept current at every phase gate.

## Tools

| Tool | Used for |
|---|---|
| Claude Code (Anthropic, model Claude Opus 5.5) | Wrote most of the code, tests and docs in this repo, ran the test suites, set up the Supabase project and the interim Render deployment through connected accounts, and reviewed its own diffs. |
| Anthropic `frontend-design` skill | Design process guidance (plan, critique against generic defaults, build, critique by screenshot). |

## What the AI generated (so far)

- Estimator library `packages/notchcount_stats` and its tests.
- API (`services/api`), database migration, job queue, invite sign-in, pass-integrity rules and their tests.
- Worker runner skeleton (`services/worker`).
- Web app (`apps/web`): capture screen, offline queue, team admin, route drawing, service worker, Playwright test.
- Docs: `docs/DECISIONS.md`, this file, `docs/LIMITATIONS.md`, `PROGRESS.md`, `README.md`, `docs/ARCHITECTURE.md`, `docs/TEACH_BACK.md`, `docs/ESTIMATOR_VALIDATION.md` (generated by `sim/`), `docs/ENGINE_CHECK.md`.
- Simulation harness (`sim/`), matching, ear and assignment code (`packages/pipeline`), case filing and public report, and the engine check script (`scripts/engine_check.py`).
- Draft Hindi strings (not yet checked; hidden in the app until a team member reviews them).
- The Oct 22 visual redesign (`apps/web`: tokens, badge, dashboard shell, every screen, the admin health page). It follows a reference the team chose (DECISIONS D-25). The AI wrote all of the code and adapted the reference's look to this product. The team chose the reference and decides whether to keep it.
- The Oct 23 landing and dashboard work: the street simulator (`lib/sim.ts`, `StreetSim.svelte`), the pipeline pictures script (`scripts/landing_assets.py`), the dog gallery endpoint and screen, the share dial, and MojoAuth email sign-in (D-28, D-29). The team asked for more visual impact; the AI designed and wrote these.
- Interface tests with a mocked API (`apps/web/ui/`), the in-process worker setting (D-26), the re-ID benchmark notebook (`benchmarks/reid_kaggle/`) and the demo seed script (`scripts/demo_seed.py`).

- Oct 24, outside the main Claude Code session: the project image pack (`docs/project-images/`, made by `scripts/export_project_images.py` and `scripts/capture_project_images.mjs` from the saved screenshots and the real pipeline on repository fixtures) and the thumbnail `docs/notchcount-thumbnail-3x2.png`, made with an AI image generation tool from the prompt in `docs/notchcount-thumbnail-prompt.txt`. The pack's own README labels which images are demo, mocked or synthetic.
- Oct 24, Claude Code: Deployxa project creation and deployment through Deployxa's MCP endpoint (D-30), host keys and webhook secret on both hosts, and the Devpost draft text (kept out of the repo).
